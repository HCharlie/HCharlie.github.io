# Programming Languages Roadmap Draft

Status: Draft. This detailed outline is intentionally not published on the website.

The public Mermaid roadmap should remain high-level, showing only **Programming Languages** and the planned Python, Rust, Go, and C/C++ series.

## Python

- Runtime and execution model
- Threads and the Global Interpreter Lock (GIL)
- Multiprocessing
- Coroutines, event loops, and async programming
- Packaging, virtual environments, and `uv`
- FastAPI and commonly used frameworks
- Jupyter and JupyterHub

## Rust

- Ownership, borrowing, and lifetimes
- Memory safety and concurrency
- Async Rust
- Cargo and package management
- Interoperability with C and Python

## Go

- Runtime and scheduler
- Goroutines
- Channels and `select`
- Context, cancellation, and timeouts
- Memory management and garbage collection
- Modules, workspaces, and Go tooling
- Building network services with the standard library and common frameworks

## C/C++

- Memory and object models
- Pointers and resource management
- Threads and concurrency
- Compilers, linkers, and build systems
- Debugging and profiling

## Cross-Language Topics

- Comparing concurrency models
- Package and dependency management
- Foreign function interfaces
- Choosing a language for systems, services, data, and ML workloads

## Cross-Roadmap Connections

- JupyterHub deployment can connect to the Systems & HPC roadmap.
- Runtime, concurrency, memory, and profiling topics can connect to Performance Engineering.
- GPU programming and distributed workloads can connect to Parallel & Distributed Computing.
